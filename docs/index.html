EWF2004 Service Remote

A breadboard IR transmitter that opens the service menu of an Emerson EWF2004 (Funai) CRT and adjusts its picture geometry, no original remote needed. Code, IR code files and notes: GitHub repository.

What it sends

  • EnterSLEEP on a service remote is a normal Emerson frame: device 41, function 63.
  • AdjustEvery other key in service mode uses the factory format: the frame's second half repeats the device and function instead of their complements. The TV ignores normal frames there.
normal:   {36.7k,872}<1,-1|1,-3>(4,-4,D:6,F:6,~D:6,~F:6,1,-39)+
factory:  {36.7k,872}<1,-1|1,-3>(4,-4,D:6,F:6, D:6, F:6,1,-39)+

Every hole in a numbered row, from a to e, is connected. The row numbers are a suggestion, and any free rows work if the connections stay the same.

Keep the Uno unplugged while wiring. Double-check the receiver before powering up, because swapping GND and VS can kill it. A backwards LED won't be damaged, but it won't light.

Test it without the TV

Plug the Uno in and close the Arduino IDE if it's open. Bend the LED toward the receiver, or hold white paper about 6 inches above both so the signal bounces back. Then run this from the project folder:

cd host
python remote.py selftest
ResultWhat to do
PASSThe wiring and signal are good. Move on to the TV.
FAIL: receiver saw nothingCheck the LED direction and transistor legs first. A phone camera may show the LED flickering during the test.
FAIL: receiver saw IR … didn't decodeThe LED is probably too close to the receiver. Add some distance.

Only one program can use the Uno's serial port at a time, so run one command at a time.

Use it on the TV

Warm the TV up for 20 minutes, then point the LED at its front panel from about 3 feet away. Check basic control first:

python remote.py key vol-

Then open service mode and adjust. Photograph every value before changing it.

CommandWhat it does
python remote.py send 41 63 --frames 3Enter service mode. The screen shows 058-0.06 271 A1 and a 2 in each corner.
python remote.py factory 8H-P, horizontal position
python remote.py factory 9V-S, vertical size. Send again for V-P, vertical position.
python remote.py factory ch+
python remote.py factory ch-		Change the selected value one step

Switch the TV off and on with its own power button to save and exit. Leave the other number keys alone: in the manual they open white balance, cut-off and other non-geometry items.

Never open the TV. A CRT can hold a dangerous charge even when unplugged. Width and corner shape are set inside the TV; leave those to someone who knows CRT safety.
